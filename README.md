# euler
My Project Euler work.

https://projecteuler.net/

In several Visual Studio projects, about 10 problems per project.

I started working on Project Euler in 2013, with the goal of learning some new stuff and having a little fun.

In some cases, I've copied other people's solutions into my projects, for comparison and experimentation. When I've done that, I've added a comment noting the source.

Starting with problem 77, in 2026, I've started experimenting with both GitHub Copilot and Claude Code to help me figure out the solutions. I'm trying to use AI as a coach here, not to just solve the problem for me.
The goal is to experiment with coding assistants and learn how to use them effectively.
